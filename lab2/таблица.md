### №2 Проектирование класса

| Элемент | Описание |
| :--- | :--- |
| Имя класса | `Movie` |
| Поля | `title` — название фильма; `duration` —  продолжительность; `rating` — рейтинг; `releaseDate` — дата выхода |
| Конструкторы | `Movie()`; `Movie(string title, int duration)`; `Movie(string title, int duration, double rating, ReleaseDate releaseDate)` |
| Методы чтения | `getTitle()`; `getDuration()`; `getRating()`; `getReleaseDate()`; `print()` |
| Методы изменения | `changeTitle()`; `changeDuration()`; `changeRating()`; `changeReleaseDate()` |
| Инварианты | Название не должно быть пустым; продолжительность не может быть отрицательной; рейтинг должен находиться в диапазоне от 0 до 10; дата выхода должна быть корректной |
